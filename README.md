# E-Commerce Sales & Customer Performance Analysis

Data analytics project analysing e-commerce sales, customers, sellers,
products, payments, delivery performance, reviews, customer lifetime value,
and RFM customer segmentation.

## Tools

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI

## Project Structure

- `data/` — cleaned datasets
- `notebooks/` — Python data cleaning and EDA
- `sql/` — SQL analysis and Power BI views
